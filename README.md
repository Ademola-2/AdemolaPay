# AdemolaPay — Homepage starter

This is the first frontend milestone for AdemolaPay, a planned Nigerian airtime, data, and bill-payment platform.

## Files
- `index.html` — homepage structure
- `css/style.css` — responsive styling
- `js/script.js` — mobile navigation and current year

## Run
Open `index.html` in a browser, or deploy the repository to a static hosting provider.

## Important
This is a frontend design prototype. It does not process real payments or recharge services. Before launch, add a secure backend, authentication, payment verification, VTU provider integration, transaction reconciliation, and appropriate security rules. Never place secret API keys in frontend files.
